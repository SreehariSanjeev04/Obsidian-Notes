    The actual shit

    IP address -> to route the data across the network to the correct network (L3)

    MAC Address -> (L2) hard coded in NIC, permanent, unique identifier used for communication wihtin a single local network. Switches use the MAC address to forward the data frames, doesnt care about IP addresses.

    When a devices wants to send data to another device on the same network, it knows the destination ip but no the mac address, using ARP it broadcasts for receiving the mac address for communication.

    Components

    Optical Fibre

    SMF - Allows single path for light to travel. Long distances use (160 or more) (yellow)

    MMF -Multiple light paths. Distance to few hundreds. (Orange)

    SFP (Small Form factor Pluggable) - transceiver that plugs into a switch and acts as an interface between the device and fiber optic cable.

    SFP (1 GB) SFP+ (10)

    Copper Cables

    Twisted Pair Cables - Unshielded Twisted Pair (UTP) - more susceptible to interference (CAT5e, CAT6) - Shielded - Mesh over twisted pairs. Coaxial - Long copper cable in the middle with plastic jacket.

    Different Networks

    Sending to the Gateway (ARP for the router MAC Address)

    Routing the Packet

    Sending to the Next Hop (constant encapsulation and decapsulation)

    Final Delivery - ARP for destination MAC address, and sends

    Frame -> specific structure to ensure the data is delivered correctly on the local network.

    Access Point

    Networking device that creates a wireless local area network, it connects to a wired network and broadcasts a WiFi signal.

    LAN

    Group of interconnected devices (computers, printers, servers) that communicate.

    Physical LAN -> actual hardware based network setup

    Virtual LAN -> software defined or logically created network that may or may not depend on a physical system (VLAN, VLAN, Virtual Switch)

    VLAN (Virtual Local Area Network)

    Logical grouping of devices in a network - Every ethernet frame gets an extra VLAN tag (802.1Q standard) that says this packet belongs to VLAN x, without L3 Switch or Router, VLAN cannot talk to each other. - Trunk and Access Ports - [ Destination MAC | Source MAC | VLAN Tag (4 bytes) | EtherType | Payload | FCS ] for VLAN Tagging

    Frame

    Basic unit of data at L2, encapsulates the data packet at L3 and adds headers and metadata. Necessary for sending the data across a physical network.

    How data is transported

    • Application Layer (Layer 7): This is where your data originates. When you use an application like a web browser to send a request (e.g., typing a URL), the application creates the raw data. This data is then handed down to the layers below.

    • Transport Layer (Layer 4): The data from the application layer is broken down into smaller pieces called segments (if using TCP) or datagrams (if using UDP). The transport layer adds a header containing port numbers for the source and destination application, which allows the data to be delivered to the correct program on the receiving computer. It also includes information for error checking and flow control.

    • Network Layer (Layer 3): The segments or datagrams are now encapsulated into packets. This layer adds an IP header that contains the source and destination IP addresses. This is the crucial information that a router uses to determine the best path for the packet to travel across different networks.

    • Data Link Layer (Layer 2): The packets are then encapsulated into frames. The data link layer adds a MAC address header and a trailer. The MAC addresses are the physical addresses of devices on the same local network (LAN). The header contains the MAC address of the sender (your device) and the MAC address of the next-hop device, which in this case is your router. The trailer contains an error-checking sequence.

    • Physical Layer (Layer 1): Finally, the frame is converted into a stream of raw bits (electrical signals, light pulses, or radio waves) and sent across the physical medium (e.g., Ethernet cable, Wi-Fi).

    Firewall

    Firewall inspects the data packets flowing through it and compares the header with the rule set.

    • Captive Login
    • 802.1X

    Interface

    Interface is the point where a device connects to a network. Physical or virtual entry. - NIC - example, Ethernet port which is part of NIC - Wireless Card Virtual Interfaces

    Each interface is assigned a MAC Address and IP address

    Networking modes in VirtualBox

    • NAT - VM gets its own private IP address from a virtual DHCP server in VirtualBox. The VM can access the internet but cannot be accessed directly by other devices on your local network.
    • Host computer acts as a router. VM sends a packet to the internet, host's NAT translates private IP to public IP.
    • Bridged Adapter - VM acts like a separate, physical machine on your network. Virtual network adapter is directly bridged to the host's physical network adapter.
    • Host Only - that is completely isolated and exists only between the host and its virtual machines. VLANs are created on bridged network so that it is connected with a physical medium to read the vlan tag

    pFSense

    OS for dedicated firewall and router.

    • Add port forward in pfSense:

      • Go to Firewall → NAT → Port Forward

      • Interface: WAN

      • Protocol: TCP

      • Destination: WAN address

      • Destination Port: 80 (HTTP) or 443 (HTTPS)

      • Redirect target IP: your webserver IP on WAN

      • Redirect target port: same (80/443)

      • Save + Apply

      This ensures pfSense accepts WAN traffic and forwards it.

    • Enable NAT Reflection (hairpin NAT):

      • Go to System → Advanced → Firewall & NAT

      • Under Network Address Translation → set NAT Reflection mode for port forwards = Pure NAT

      • Enable Automatic outbound NAT for Reflection

      • Save

      This allows VLAN clients to hit the WAN NAT IP and be redirected back inside to the webserver.

    • Firewall rules:

      • On WAN: allow inbound HTTP/HTTPS (pfSense may auto-add with the NAT rule).

      • On VLAN interfaces: allow traffic to WAN IP on port 80/443.
